### 💳 [Fault-Tolerant Payment Ledger](https://github.com/shivam9473/Fault-toleant-payment)

A full-stack money-transfer system designed for correctness under retries and concurrent requests.

`Fastify` `TypeScript` `PostgreSQL` `React 19` `Vite` `Docker`

- Prevents duplicate transfers using durable idempotency keys and SHA-256 request fingerprints.
- Uses PostgreSQL row locking and deterministic lock ordering for concurrency safety.
- Commits debit, credit, transfer audit, and idempotency records in one atomic transaction.
